# Source-private live unowned-Link correction and tombstone

This extends the authentic runtime administration companion with `correctLiveLinkVersion(subject, revision, preparedUpdateLink)` and `tombstoneLiveLinkVersion(subject, revision)`. It adds no BDP Operation, HTTP route, CLI/configuration option, package export or Mutation Receipt. The public runtime facade keeps its same six keys; spread copies cannot acquire administration. Administrative acts keep the epoch and commit one new transaction/group position.

Correction requires the exact current canonical Link and revision, an explicit matching `expectedRevision`, and exactly one prepared `updateLink`. Only complete root-object replacements of properties and common metadata are accepted. Endpoints, type and pin remain identical. The ordinary evaluator applies installed schemas, endpoint/type contracts, revision rules and caps. A no-op correction is refused; it never silently becomes a deletion. Tombstone is a separate explicit call using ordinary `deleteLink` safety and fact generation.

An in-Scope source whose descriptor owns this LinkType (including wildcard ownership), or whose current Bead has any nonempty owned set, is refused before evaluation or durable writes. This unit implements no owned-Link/source-Bead cascade. An external source has no local owning Bead; its unchanged Reference, including any pin, remains governed by the ordinary Link contract and evaluator. Every accepted Link still has an in-Scope endpoint under existing rules.

Both paths reuse the existing atomic historical purge, digest/ledger retention, receipt and sequence scrubbing, Snapshot invalidation, ordinary Read cache observers and publication fences. A corrected successor emits the existing content-free full-root updated delta with the erased previousRevision. Tombstone emits the ordinary identity-only deleted and applicable unlinked facts. Before encoding the new group, it applies the existing last-endpoint-bearing-version withholding rule: unlinked facts remain while an older endpoint-bearing Link version exists, and disappear when the last such version is erased. Prospective retained-version detection streams index rows and stops at the first unselected version; it does not allocate the subject's complete history. The bounded selected plan is shared with historical purge; prior retained groups keep the same withholding/cursor treatment.
