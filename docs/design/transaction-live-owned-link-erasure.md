# Source-private live owned-Link erasure transitions

This extends the existing authentic `correctLiveLinkVersion` and `tombstoneLiveLinkVersion` administration companion to Links owned by their in-Scope source Bead, including wildcard ownership. It adds no public facade key, Operation, HTTP route, configuration, CLI, package export or Mutation Receipt. The exact base is `07ee74a70f80465e06937f1fa8dd812d86b4e8ed`; the agreed specification remains unchanged.

The existing ordinary `updateLink` / `deleteLink` evaluator creates both the Link transition and its fresh source Bead version. It rebuilds the complete owned set from current outgoing Links, preserving unaffected siblings, source properties/common metadata, ordinary attribution and endpoint/pin rules. Administration never supplies a replacement owned set or rewrites endpoints. Correction still requires one exact canonical current Link, matching revision and `expectedRevision`, and complete properties/metadata root replacements. A no-op remains a refusal, not an implicit delete. Ordinary installed schema validation and owner bounds still apply.

The new helper checks the two-postimage transition and ordinary fact structure. A property/common-metadata correction replaces the Link fact's deltas with complete root replacements and puts the same content-free delta inside the source's sole `ownedLink.updated` transition. The source has no direct object delta. A tombstone retains ordinary identity-only `deleted` / `ownedLink.deleted` transitions and the complete remaining source set. The owning source gets a fresh revision even when its own properties are unchanged; the target is not versioned. This follows specification lines6456–6500, not a new erasure interpretation.

Both successor postimages are retained inside the same SQLite transaction before the existing historical cascade is planned. Every retained source version that inlined the erased Link version joins that plan, including multiple historical source versions. The shared purge removes copies from groups, receipts, sequences, snapshots and indexes and commits digests/permanent lineage plus one administrative group. Existing publication and replay fences remain shared.

When withholding the last endpoint-bearing Link version removes intermediate `unlinked` facts from the new administrative group, surviving source Event ordinals stay unchanged. The owner now records the same content-free gap commitments and private erasure-framing metadata it already uses for older pruned groups. These private flags are not exposed in the public changefeed. A surviving older Link version still permits graph facts. External targets induce no fabricated external endpoint Event; their pins remain unchanged.
