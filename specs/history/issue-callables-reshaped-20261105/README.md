# Command-shaped Issue Callables, set aside

These three files are exact copies of `specs/types/issue/callables.md`, `specs/types/issue/issue-callables-preview-1.schema.json` and `specs/types/issue/issue.md` at commit `5fd07f1d2e2d` of this repository. They hold the command-shaped draft of the Issue Callables, which reshaped the product's v0 operations into views over Bead records. Donna's ruling of 2026-11-05 set that draft aside for the sprint in favor of plain routing over the product's v0 HTTP API.

This directory is history, not authority. It supplies no requirement to the current specification. Read [Issue and Dependency Types](../../types/issue/issue.md) and [Issue and Dependency Callables](../../types/issue/callables.md) instead.

The copies are unedited, so their relative links resolve from their original location and not from here. `scripts/spec-schema-fragments.mjs` does not read this directory.
