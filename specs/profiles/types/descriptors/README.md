# Intrinsic descriptor documentation

[Types §2.1](../types.md#21-type-beadtype-and-linktype) adopts the [Type-definition Markdown0.1 notation](../../../formats/markdown-type-definitions.md) for these authoritative readable expressions of the selected intrinsic-2 descriptors and their recorded owned Refines declarations. They instantiate the existing contract, rather than selecting a second descriptor model. Field meanings, category/constraint interpretation and admission remain in Types; exact published values remain bound by the immutable [intrinsic-2 publication](../intrinsic-2.json). Any disagreement is a defect to repair, not permission to choose a convenient authority.

Each file uses recorded mode. The title's category describes instances; every definition is itself a Bead. Properties-schema files are the existing exact JSON companions, not a new schema dialect. Schema-resource rows bind complete supplied JSON files, with their original IDs, bases, dialects and references. The eight [standard-resource documentation companions](schema-resources/) exactly reproduce the retained values embedded in publication2; the additional application binding for BeadType/LinkType uses the existing Type2 companion. File locations are documentation bindings, not network fetches or alternative schema identities. Supply the Types directory, including these documents and the intrinsic-2 companions, as the local documentation bundle. The retained standard resources keep their [third-party notices](../THIRD_PARTY_NOTICES.md).

Only Type writes `abstract:true` and an instance `ownsOutgoing` selector here. BeadType and LinkType inherit ownership for their definition Beads through their exact Refines declarations; the documents do not insert an `ownsOutgoing` descriptor into either. Refines keeps two correlated category-preserving endpoint pairs. It introduces no generic `acyclic`, `unique`, `allowSelf` or finite maximum setting; special exact-revision conformance DAG and exact-parent uniqueness remain Types rules. Floating declaration sources remain literal recorded References; their captured owning edition, not an invented source pin, establishes ownership context.

These are exact **publication source records**, including recorded member absence. The frozen publication predates common required metadata: definition and declaration source records omit metadata, and the notation preserves that omission. [Core's current complete-read projection](../../core/core.md#resource-records) of pre-metadata state to `metadata:{}` is a separate serving rule, not a rewrite of the immutable publication or these source documents. No revision provenance, descriptive text, SemVer label, local rule, default or empty map is manufactured. An empty Refines section preserves a known empty owned capture; it does not infer emptiness from unavailable historical state.

The focused artifact tests check literal document bindings, descriptor schemas, exact references, owned declarations and complete local schema-resource correspondence. They do not execute a Type-format parser, compiler, converter or round trip. Recorded source documentation is not an installation envelope, registration/default choice, ordinary revision allocation, provider/native implementation or runtime Types1 qualification. A future Type-format tool and its independent evidence remain deferred. The illustrative authoring examples under fixtures/markdown-types remain examples; they are not promoted into this intrinsic publication.
