# Packed installed unowned live-Link boundary

This private fixture exercises exact production source `47ae595665e424bcdeb776c2bd74183fa5784537` through fresh local tarballs installed offline. It is not a public administrative CLI, HTTP operation, configuration field or package export.

The child dynamically imports the installed configuration capture, payload identity, runtime, authentic runtime administration companion and `prepareTransactionSingleton`. It keeps the original six-key runtime facade. One prepared full-root property/metadata correction and one last-version tombstone are permitted for `links/l`; duplicate administrative calls are refused. No public mutation receipt is created by administration.

The installed test uses ordinary HTTP to create two healthy endpoint Beads and a pinned unowned Link, then binds the following observations to that actual installed configuration:

- caught-up SSE receives atomic correction at pos-2 and tombstone at pos-3;
- independent known full-record JSON canonicalization verifies both erasure digests;
- properties/metadata root deltas and previous/new revisions are exact, with endpoints/pin unchanged by correction;
- tombstone change and deleted Event contain only identity/revision, with no old Link content;
- pre-erasure Snapshot, pagination continuation and finite checkpoint expire;
- an erased Event's old exclusive cursor remains valid; after last-version erasure, Scope/endpoint/Link Event Sources withhold graph facts and retain the appropriate identity deletion;
- same-key replay and receipt retrieval expose erased lineage, healthy endpoint records and the permanent two-record ledger survive same-epoch reopen.

Event IDs are source-local. Endpoint records are compared against their original endpoint-source observations; a newly emitted Link-source deletion is compared with identical semantic data, an exact source URL, and a bounded opaque source-local ID. The fixture does not demand the Scope projection's token in another Event Source.

Set `BDP_LIVE_LINK_INSTALLED_ENTRY`, `BDP_LIVE_LINK_SOURCE` and `BDP_LIVE_LINK_EVIDENCE` explicitly. The optional `BDP_LIVE_LINK_BUILD` points at the exact emitted source tree used for full server-module equality checks. Default CI runs pure negative oracles and skips the installed case without an explicit packed target. Raw observations contain the private bearer configuration and are written0600; publish only redacted completion data.

All allocation/startup is inside owned cleanup. SSE close, child close, temporary-directory removal and evidence writing are independently attempted; errors are combined after `finally`. Bounds use the existing fixture pattern: 45-second cohort AbortSignal, 60-second test, 10-second child-control deadlines, 15-second SSE recorder, finite40-request ceiling and existing HTTP body/header limits. The external observer supplies its existing90-second watchdog and raw-log capture.
