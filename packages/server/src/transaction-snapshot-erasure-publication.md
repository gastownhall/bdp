# Retained Snapshot erasure publication race

An actual Node HTTP request can finish its synchronous Snapshot owner read before an erasure commits, then reach final publication after that commit. The existing final guard correctly withholds the stale body, but previously returned an unclassified bodyless500 even for the now-expired actual retained page. The erasure contract explicitly makes that old Snapshot410 cursor-expired.

Only successful actual manifest/page selections now retain a closed, source-private target descriptor through HTTP shaping. A same-epoch/view erasure-floor fence carries its actual current owner context; context-mismatch fences remain unclassified. For that exact retained target only, runtime makes one existing expiry diagnosis, with no minimum wait, handler replay, initial capture or mutation retry. It emits410 only if the existing owner reports cursor-expired in the same epoch/view and a final publication check still succeeds. Competing lifecycle/context failures fall back to the previous generic error; there is no retry loop.

Direct Resources, Event Sources, receipts, initial Snapshot capture/preflight and original problem selections receive no retained-target marker. Their mappings remain unchanged. No foreign/expired/minimum priority or retained-history permission decision is made.

The new fixture uses the existing private real-time clock observer. It returns Date.now unchanged, resets one-shot arming before scheduling a microtask, and calls authentic same-facade local erasure only after the synchronous owner entry releases. No fake clock value, new scheduler/debug API or owner-truth callback is used. The configuration is nonordinary, with no claimed ordinary configuration identity. A real issued second page over33 Beads, then a healthy successor, exposes the boundary: RED500 versus GREEN410; fresh same-page GET/HEAD remain410, the current successor stays200, and native SQLite inspection proves only one Snapshot with the same absolute expiry. All raw responses, failure history and bounded cleanup evidence are retained externally.
