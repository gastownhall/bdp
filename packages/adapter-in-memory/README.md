# Reference fixture revisions

bdptest-fixture-literal-v1 uses fixture-authored opaque revision strings. It does not derive revisions from properties or any numeric serialization. The packaged reference fixture and its portable realization carry the same literal revisions. The conditional content-derived numeric-revision obligation is not applicable to this discipline.

The exact declaration is bound in the portable conformance fixture under `oracles.numeric-model.declaration`; the successor observation tests require agreement with this document.
